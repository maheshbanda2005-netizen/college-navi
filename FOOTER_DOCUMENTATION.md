## 🔧 Customization

### To Update Developer Information

Edit these lines in `Footer.tsx`:

```typescript
// Developer name
<h3 className="text-2xl font-bold text-white mb-2">👨💻 Mahesh Banda</h3>

// Email
<a href="mailto:mahesh@edunavigator.ai">

// Portfolio
<a href="https://maheshbanda.com">

// Social links
{ label: 'GitHub', url: 'https://github.com/maheshbanda', ... }
```

### To Add More Links

Add to `quickLinks` array:
```typescript
{ name: 'New Link', href: '/new-page' }
```

Add to `resources` array:
```typescript
{ name: 'Resource Name', url: 'https://example.com' }
```

Add to `socialLinks` array:
```typescript
{ label: 'Platform', url: 'https://example.com', icon: '🎯', color: 'hover:text-color' }
```
